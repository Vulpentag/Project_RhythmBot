# Project_RhythmBot
RhythmBot es un projecto pensado en automizar y tener una forma afk de ganar puntos en un juego de ritmo, hecho con c++
y usando deepseek como apoyo. este projecto se hizo en una laptop con: \n
 |AMD Athlon 300U with Radeon Vega Mobile Gfx 2.40 GHz
 |8 GB RAM (5.94 GB usable)
 |Windows 10 64-bit
 |Screen resolution: 1366 x 768
en caso de que deje este pequeño trabajo como publico. espero que tenga apoyo. esta idea nació debido que no siempre estaba ahí para jugar, así que esta es una alternativa para no perder mucho tiempo y poder hacer algo mientras que el juego esta, asi tengo tiempo para ir a baño o a hacerme algo de comer
